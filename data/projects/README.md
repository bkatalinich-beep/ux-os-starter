# Initiatives

One folder per design initiative, named with a date prefix so the archive stays chronological: `2026-08-tab-groups`, `2026-09-onboarding-refresh`. The date is when the initiative started, and it never changes.

Each initiative folder starts with a `brief.md` (copy the template from [templates/](../../templates/)) and accumulates whatever the work produces: drafts, research synthesis, meeting notes. Keep artifacts close to the work they belong to instead of in a shared pile.

Decisions can start in the root [decisions.md](../../decisions.md) registry. If an initiative generates enough of them, give it its own `decisions.md` inside its folder and leave a pointer in the root registry.

An example skeleton is in [2026-07-example-initiative/](2026-07-example-initiative/); rename or delete it once you have a real one.
