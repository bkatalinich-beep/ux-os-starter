# Context library

Stable context lives here: the information that stays true for months and that you find yourself re-explaining. Good candidates are a short description of your product area, your team's design principles, and a stakeholders file that says who the key people are and what each of them cares about.

Keep each file short and current. When something here goes stale, fix it in the moment you notice, because a context library you cannot trust is worse than none.
